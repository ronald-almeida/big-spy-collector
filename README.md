# BIG Spy Collector

Worker com diagnóstico do primeiro lote da Biblioteca de Anúncios.

O segredo COLLECTOR_TOKEN deve ser mantido na Cloudflare, nunca no repositório.

Para Cloudflare Workers Builds: comando de build vazio; deploy `npm run deploy`; raiz do projeto `/`.

Ainda não houve uma busca real bem-sucedida na Cloudflare. O log Página recebida do Facebook permite investigar o conteúdo retornado.
